Fake News Detection System

Introduction

Fake News Detection System is a Python-based Machine Learning project that identifies whether a given news article is Real or Fake.

Objective

The main objective is to detect misleading or false news using Machine Learning techniques.

Technologies Used

- Python
- Google Colab
- Pandas
- Scikit-learn
- Natural Language Processing (NLP)

Features

- Takes news text as input.
- Analyzes the entered news.
- Predicts whether the news is Real or Fake.

How to Run

1. Open the Jupyter Notebook.
2. Run all code cells.
3. Enter news text.
4. View the prediction.

Expected Output

The system displays REAL or FAKE based on the model prediction.
